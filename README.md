## 📌 Overview

**Nano Career Portal** is an **AI-inspired Placement Management System** developed to streamline recruitment workflows for students, companies, and administrators.

The platform enables students to register, explore placement opportunities, apply to drives, and track applications, while companies can create placement drives and manage recruitment efficiently.

The system is designed with a scalable architecture and recruiter-friendly workflow, inspired by modern career platforms and placement ecosystems.
