# Placement Portal Application (MAD-I)

## Demo Video
watch demo =: https://drive.google.com/file/d/1PshRweBOT7J3H2CLYBKnM1a9jD6VNBjH/view?usp=drive_link

This is a web-based Placement Portal built using Flask and SQLite.

## Features
- Student Registration
- Company Registration
- Admin Dashboard
- Placement Drives Creation
- Job Application System

## Tech Stack
- Flask (Python)
- SQLite
- HTML, CSS, Bootstrap
